ATL LAB MANAGER - VERCEL / PWA PACKAGE

WHAT IS INCLUDED
- index.html: existing ATL Lab Manager, responsive CSS refresh, 3D Printing job register.
- manifest.webmanifest + icons + sw.js: installable PWA app shell.
- supabase_3d_printing.sql: create the 3D printing database table and RLS policies.
- vercel.json: static hosting configuration.

BEFORE DEPLOY
1. Open supabase_3d_printing.sql and run it in Supabase Dashboard > SQL Editor.
2. Check index.html contains your Supabase project URL and publishable key. The publishable key is intended for browser use; never put a service_role/secret key in this file.
3. Test login, Students, Projects, Components, Issue / Return and 3D Printing locally.

VERCEL DEPLOY
1. Create a GitHub repository and upload the contents of this folder to its root.
2. In Vercel choose Add New > Project and import that repository.
3. Framework Preset: Other. Build Command: leave empty. Output Directory: leave empty or use ./ .
4. Deploy. Vercel will serve index.html as a static site.
5. Add your production domain to Supabase Authentication > URL Configuration > Site URL and Redirect URLs. Add both https://your-domain and https://your-domain/** as applicable.

CROSS-DEVICE
The app uses Supabase Auth and Supabase tables, so users signing into the same deployed URL see shared cloud records according to their RLS permissions. Do not use localStorage as the shared database.

ANDROID APP
This is a PWA, not a native APK. After deployment over HTTPS, open the site in Chrome on Android and use Install app / Add to Home screen. To package an APK/AAB, use PWABuilder with the deployed URL and follow its Android/TWA signing steps. The APK is not generated by this static website package.

OFFLINE LIMITATION
The service worker caches the app shell only. Supabase authentication and reading/writing cloud records require internet.
